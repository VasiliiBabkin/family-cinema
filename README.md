# Family Cinema

Частный семейный кинотеатр для Android, планшетов и Android TV / Google TV. Основной язык — русский.

## Принципы
- Детям доступен только одобренный родителем контент; никакого свободного поиска, браузера или переходов к внешним рекомендациям.
- Родитель управляет источниками, проверками, загрузками, профилями и PIN.
- Поиск отделён от воспроизведения. Источники расширяемы: Torznab, документированные API, magnet и .torrent.
- Потоковое воспроизведение BitTorrent проектируется как отдельный модуль; для тестов использовать контент с подтверждёнными правами.
- Серверный gateway на собственном VDS для поиска, кэширования и разрешённых сетевых маршрутов; не обещать обход любой блокировки.
- Никаких секретов в Git или APK; конфигурация через переменные окружения и защищённое хранилище.
- Никаких фиктивных кнопок и демонстрационных результатов, выдаваемых за рабочие.
