# Доставка APK в Google Drive

## Обязательное требование
После каждой успешно проверенной сборки APK в Codex Cloud пытаться доставить файл в Google Drive, папка `Family Cinema` (папку и её ID нужно один раз согласовать с владельцем). GitHub Actions не требуются; не включать автоматические Actions.

## Алгоритм
1. Собрать APK для нужного target (mobile/TV) и variant (debug/release).
2. Убедиться, что файл существует, размер >0, проверить Android-подпись и выполнить доступные тесты.
3. Вычислить SHA-256; сформировать имя `family-cinema-v<version>-<target>-<variant>.apk`.
4. Проверить, что в текущей среде есть разрешённый способ загрузки в Google Drive (доступный коннектор, OAuth либо сервисный аккаунт с доступом к целевой папке). Не считать наличие Google Drive у пользователя автоматическим доступом для Codex.
5. Если доступ есть, загрузить APK; проверить metadata загруженного объекта, размер и по возможности скачать обратно и сверить SHA-256. Возвратить точную ссылку и Drive file ID.
6. Если доступа нет, честно пометить Drive upload как BLOCKED, сохранить локальный APK/доступный артефакт и дать инструкцию по однократному подключению. Не публиковать фиктивные ссылки и не выдавать частичную загрузку за успех.

## Безопасность
- Репозиторий публичный: токены, OAuth refresh tokens, JSON-ключи сервисных аккаунтов и приватные ссылки никогда не коммитить.
- Хранить секреты в защищённых переменных среды/секретах разрешённого инструмента.
- Не делать APK общедоступным по ссылке без явного согласия владельца.
- Не давать лишних прав на весь Drive, если достаточно доступа к одной папке.
- Не удалять старые APK без отдельной политики хранения.
- Если OAuth/service account невозможны, предложить ручную первичную авторизацию; не пытаться обходить её.

## Отчёт после сборки
Версия, target, variant, путь к APK, размер, SHA-256, статус тестов, статус Drive upload (PASS/BLOCKED/FAIL), Drive file ID и точная ссылка при подтверждённом успехе.

## Приёмка
Не считать доставку реализованной, пока хотя бы один APK не загружен и не проверен в реальном Google Drive.
