# Проверочный Stremio-источник

Статический открытый источник для QA клиента: один оригинальный технический ролик проекта (349 KiB, CC0 1.0), не каталог фильмов. Исходник видео — scripts/generate-demo.sh. Каталог без запроса и точный поисковый запрос «Тихий» доступны как стандартные protocol resources. Поддерживаемый протокол приложения не ограничен этим источником; здесь нет динамического поискового сервиса. Никаких сторонних постеров/фильмов или ключей.
