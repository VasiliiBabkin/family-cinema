# 0.2.0 — Player & Native UX

Нативные Compose-экраны заменяют перегруженный MainActivity: телефонная композиция, NavigationRail и две колонки на планшете, самостоятельные экраны Android TV. Детский режим — тёплая палитра и крупная оригинальная обложка, родительский — тёмная медиатека. Русские строки вынесены в Android resources. Включены собственная Canvas-иллюстрация/иконка, переходы экранов, состояния PIN, пустого каталога и ошибок плеера.

Полноэкранное видео Media3 сохраняет пропорции FIT, на телефоне запрашивает sensor-landscape, возвращает исходную ориентацию при выходе. Скрываемый единый overlay содержит только работающие действия: play/pause, ±10 секунд, шкалу, время и выход. Касания, D-pad, OK, Back и медиа-клавиши используют одно состояние. ViewModel удерживает один ExoPlayer при пересоздании Activity; SurfaceHolder callback восстанавливает paused кадр. Позиция сохраняется, фон ставит видео на паузу; взрослый предпросмотр закрывается вместе с родительской сессией.

Сохранены создание PIN, солёный хеш, блокировка после пяти ошибок, одобрение точной версии и отзыв с подтверждением. Никакой родительской авторизации в сохранённом состоянии. Старые интерфейсы источников и будущего torrent engine сохранены; реализации сетевого поиска и BitTorrent не добавлялись.

Сборка APK и тесты выполнены в облаке без GitHub Actions. Приватный Google Drive получил настоящий APK, скачивание обратно подтвердило размер, SHA-256 и подпись. [QA](../QA.md), [реальные скриншоты](screenshots/v0.2.0/README.md), [доставка](APK_DELIVERY_STATUS.md).

Это debug-версия с одним собственным техническим роликом. Физические устройства, широкая матрица кодеков/TV-пультов, TalkBack, production signing, поиск, backend-синхронизация, профили и временные лимиты остаются за пределами подтверждённого объёма. Конкретные результаты и ограничения перечислены в QA.
