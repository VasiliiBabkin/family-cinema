# Архитектура этапа 1

- `app`: Compose, отдельная двухколоночная TV-оболочка при `UI_MODE_TYPE_TELEVISION`, мобильная вертикальная навигация и боковая панель навигации для планшетов от 840 dp. Один universal APK, minSdk 26, target/compileSdk 35. Native P2P-библиотек нет, собственных ABI-зависимостей пока нет.
- `domain`: произведение, неизменяемая версия, одобрение точного fingerprint. Эпизод входит в fingerprint.
- `parental`: локальные закрытые SharedPreferences, PBKDF2-HMAC-SHA256 (120000 итераций), случайная соль, константное сравнение. PIN подтверждается при создании. После пяти ошибок блокировка на минуту, состояние переживает перезапуск. Родительская сессия в памяти; сбрасывается при уходе приложения в фон. Backup выключен. Это защита интерфейса, не защита от владельца root или очистки данных.
- `player`: Media3 ExoPlayer и PlayerView, локальный asset. В app перед стартом проверяются байты SHA-256; Media3 не получает torrent URI. Позиция сохраняется при закрытии/ON_STOP, воспроизведение останавливается в фоне; ресурсы освобождаются при выходе. После возвращения из фона требуется Play. При смене конфигурации экран возвращается в безопасный каталог; позиция остаётся.
- `sources`: только типизированные интерфейсы поиска, Torznab и torrent engine; реализаций и фиктивных ответов нет.
- `backend`: FastAPI health + пустой типизированный каталог, Pydantic-контракты источников/поиска. PostgreSQL, авторизация и синхронизация не реализованы. Каркас нельзя выдавать за готовый сервер этапа 2.

Данные ребёнка локальны. Поиск, сайты и сетевые URI недоступны из детского режима. В манифесте нет разрешения INTERNET: APK этапа 1 намеренно автономен. При следующем этапе потребуется отдельно проектировать серверную авторизацию и защиту от изменения содержимого удалённого источника.

Строки приложения сейчас русские непосредственно в Compose; Media3 получает русскую конфигурацию Activity. Для дополнительных языков предстоит извлечение строк в ресурсы. UI не использует вымышленные постеры: единственная карточка явно обозначена как собственное тестовое видео.

До интеграции P2P обязательны: лицензия native engine, поддерживаемые ABI, проверка файла и контента, ограничение диска, отмена, seek/container-aware piece priorities, предупреждение родителю об IP и раздаче. Успешный HTTP gateway не доказывает доступность Android-пиров.
