# Инструкция родителю — Family Cinema 0.3.0

## Установка и сохранение данных

Установите APK поверх 0.2.0 с той же подписью, **не очищая данные приложения**. ARM64 APK предназначен для arm64-v8a; для других поддерживаемых архитектур нужен universal APK. Debug-подпись — для испытаний. PIN остаётся прежним, одобрение и позиция прежнего ролика переносятся в Room. После запуска родительский сеанс закрыт, автоодобрение выключено.

Сервер, учётная запись, PostgreSQL, Jellyfin и компьютер для работы не нужны. Для собственных файлов и уже проверенных копий интернет не нужен.

## Личное видео

1. Откройте замок, введите PIN. На первом запуске создайте и повторите PIN из 4–8 цифр.
2. Откройте «Медиатека» (значок библиотеки в верхней панели), затем «Добавить» → «Личный файл».
3. Укажите настоящее название и проверенную возрастную рекомендацию. Пустой возраст означает отсутствие детского доступа. Для сериала включите соответствующий переключатель, укажите сезон/серию. Чтобы добавить следующий эпизод локального сериала, используйте то же название сериала.
4. Выберите видео системным файловым диалогом. Если диалог увёл приложение в фон, после возвращения подтвердите PIN ещё раз. Выбор не даёт бессрочной родительской авторизации. На TV без системного файлового диалога нужен совместимый файловый менеджер или другой источник.
5. Создаётся приватная копия, проверяется наличие видео и SHA-256. Исходный файл не изменяется. Найдите произведение в медиатеке, откройте карточку, просмотрите версию и подтвердите «Разрешить ребёнку».
6. Выйдите из родительского режима значком ребёнка. Детская библиотека содержит только разрешённые версии, соответствующие возрастному пределу.

Название, оригинал, альтернативные названия, описание, год, жанры и возраст можно исправить в карточке → «Изменить описание». Метаданные не заменяют проверку содержимого. Для продолжения просмотра откройте ту же версию: позиция привязана к конкретному видео.

## HTTPS и совместимые каталоги

В «Источниках» можно добавить личную HTTPS-ссылку на видеофайл или HTTPS-адрес `manifest.json` совместимого Stremio addon. Подтвердите право использовать его контент/изображения; затем приложение проверит manifest и поддерживаемые возможности. Node.js и сервер SDK на Android не устанавливаются. На TV адрес вводится в системном защищённом поле; завершите ввод кнопкой «Готово», затем подтвердите права и подключение. На телефоне/планшете используется стандартное Material-поле.

В медиатеке введите название и нажмите «Найти» для поиска в подключённых источниках. Локальная фильтрация работает сразу, в том числе без сети; русские варианты, ё/е, альтернативные имена и транслитерация учитываются локально. Поддержка онлайн-поиска зависит от объявленных `search` возможностей addon. Издатель источника отвечает за точность метаданных, наличие потоков и доступность.

В карточке запросите подробности/серии, выберите эпизод и «Найти версии». Для родительского HTTPS-предпросмотра доступен Media3; для разрешения ребёнку видеофайл сначала скачивается и проверяется. Таким образом, изменение удалённого URL не заменяет уже одобренные ребёнку байты. HLS/DASH — только родительский online preview; детский импорт рассчитан на самостоятельные видеофайлы. Неподдерживаемые торрент-варианты явно помечены, кнопки фиктивного воспроизведения нет.

Приложение отклоняет HTTP без TLS, IP-адреса, локальные/служебные DNS-адреса, redirects и URI с логином/паролем. LAN/Jellyfin и произвольные web pages этим клиентом не поддерживаются. Конфигурационные ключи внутри URL шифруются Android Keystore; не публикуйте личный manifest URL. Обработчики произвольных заголовков авторизации и DRM не реализованы.

Открытый проверочный источник проекта (один собственный CC0-ролик, **не каталог фильмов**):

`https://raw.githubusercontent.com/VasiliiBabkin/family-cinema/codex/player-fullscreen-0.2/docs/qa-addon/manifest.json`

Он предоставляет каталог и точный поисковый запрос «Тихий». Это статический QA fixture: не ожидайте от него поиска любых фильмов. Поддерживаемый клиент приложения не ограничен этим fixture. Другие провайдеры не предустановлены, ключ TMDB и медиатека Jellyfin не подключены.

## Автоодобрение и ограничения

В «Семейных настройках» задайте возрастной предел (по умолчанию 12). Включите «Одобрять автоматически» с подтверждением и отдельно выберите доверенные источники. «Личные файлы» тоже становятся доверенными только после вашего подтверждения.

Автоматическое решение требует одновременно включённой настройки, доверия к источнику, права использования, известного подходящего возраста и проверенной конкретной копии. Для удалённого автоодобрения дополнительно нужен ожидаемый SHA-256, объявленный источником и совпавший с файлом (необязательное расширение `sha256` stream). Обычные addons без него требуют ручного одобрения; имя файла, infoHash и OpenSubtitles hash не заменяют SHA-256. Поиск/постер/название не разрешают видео. Неизвестный возраст и неподходящая версия остаются недоступны. Ручной запрет сохраняется; SHA-256 запрещённого содержимого учитывается и при другой ссылке. Новый fingerprint не наследует старое одобрение.

Выключение прекращает новые автоматические разрешения и сохраняет прежние. Отозвать конкретную версию можно в карточке с подтверждением. Возрастной предел ограничивает эффективную доступность, не удаляя журнал прошлых решений. Решения, политика и источник разрешения видны в локальном журнале. Несколько одновременно управляемых детских профилей пока не реализованы; схема подготовлена с profile ID.

## Место и фон

По умолчанию копии ограничены 2 ГБ; в настройках доступны 1/2/4 ГБ. Оставляется физический резерв свободного места. Разрешённые копии автоматически не удаляются. «Удалить неразрешённые копии» требует подтверждения, после него некоторые файлы потребуется импортировать заново.

Длительное копирование показывает прогресс и отмену. Уход приложения в фон прекращает активные сетевые операции и закрывает родительскую сессию. Не рассчитывайте на фоновую загрузку после блокировки устройства. Детское воспроизведение в фоне ставится на паузу; возврат не включает звук автоматически.

Нет родительского восстановления PIN, облачной синхронизации или защиты от root/очистки данных. Это debuggable APK: человек с разрешённым ADB-доступом может прочитать private data через run-as. Полный статус испытаний и конкретного APK указан в QA.md.
